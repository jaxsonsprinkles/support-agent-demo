# support-agent-demo

Demo target agent for [AgentBisect](https://github.com/jaxsonsprinkles/agentbisect) (neatHack, Oct 2026): a tool-using customer-support agent for a small online store.

Its commit history is written by a coding agent (with Entire checkpoints) and contains three **seeded** regressions that arrive as plausible side effects of real features. They exist so AgentBisect has something to find. Status: placeholder; the agent is built in a later chunk.
